# -Creating_an_Equity_Option_Scenario_Analysis_Dashboard
Dashboard Streamlit interactif qui calcule le prix d’options européennes sur le S&amp;P 500 (Black-Scholes), affiche les Greeks et les payoffs, et simule des scénarios de marché (±10 %, ±20 %) pour montrer à un fonds de pension comment se couvrir contre une baisse.
